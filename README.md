# Proof — сервіс фактчекінгу для розслідувальної журналістики

Односторінковий сайт сервісу **Proof** — проєкту [ІРРП (Інституту розвитку регіональної преси)](https://irrp.org.ua/), який пропонує розслідувальним журналістам і редакціям незалежний фактчекінг матеріалів перед публікацією.

Сайт розповідає про сервіс і містить форму заявки: ім'я/псевдонім, медіа, контакти — команда Proof зв'язується протягом 24 годин.

Оформлення побудоване на фірмовому стилі ІРРП (лого RPDIPP/ІРРП, кольори `#002D49`, `#0073AC`, `#C6DEEE`, `#EBF7FF`), а не на стилі ProMedia.

## Структура проєкту

```
index.html            — вся сторінка (HTML)
assets/css/style.css   — стилі
assets/js/main.js      — мобільне меню
assets/img/            — логотипи ІРРП (SVG, світлі/темні, гор./верт.) та іконка глобуса
```

Це статичний сайт без збірки (build step) — просто HTML/CSS/JS, готовий до GitHub Pages.

## Форма заявки (Google Forms)

Заявка на фактчекінг — це вбудована через `<iframe>` Google-форма (секція `#request` у `index.html`, клас `.gform-embed`). Відповіді збираються там само, де налаштована сама Google-форма (наприклад, у пов'язаній Google Таблиці).

Щоб замінити форму на іншу:

1. У Google Forms відкрийте потрібну форму → **Надіслати** → вкладка **Вбудувати `<>`** → скопіюйте посилання з `src` (воно має закінчуватися на `?embedded=true`).
2. У файлі `index.html` замініть значення `src` в `.gform-embed`, а також посилання у `.gform-fallback` (без `?embedded=true`, для відкриття форми в новій вкладці).
3. За потреби скоригуйте висоту вбудованої форми (`.gform-embed { height: … }` та мобільне значення в `style.css`) — Google Forms не адаптує висоту iframe автоматично.

## Публікація на GitHub Pages

1. Зайдіть у налаштування репозиторію: **Settings → Pages**.
2. У розділі **Build and deployment → Source** оберіть **Deploy from a branch**.
3. Branch: **main**, папка: **/ (root)** → Save.
4. Через 1–2 хвилини сайт буде доступний за адресою на кшталт `https://ianitskyi.github.io/proof-factcheck/`.

Кастомний домен можна додати там само (поле **Custom domain**).

## Локальний перегляд

Достатньо відкрити `index.html` у браузері, або підняти простий локальний сервер:

```bash
python3 -m http.server 8000
```

і відкрити `http://localhost:8000`.

## Джерела оформлення

- Логобук та кольори ІРРП (RPDIPP/ІРРП) — фірмовий стиль організації.
- Опис місії та напрямів діяльності ІРРП — узагальнено за матеріалами [irrp.org.ua](https://irrp.org.ua/).
- Алгоритм і умови фактчекінгу Proof — узагальнено за внутрішнім описом сервісу ІРРП.
- Референси зі світової практики аутсорс-фактчекінгу для розслідувань: Fund for Investigative Journalism, агенція Factual, International Fact-Checking Network (IFCN/Poynter), Global Investigative Journalism Network (GIJN).
